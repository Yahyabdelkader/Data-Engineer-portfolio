Public API Data Collector

An automated Python data ingestion worker that queries free public REST APIs on a scheduled cron cadence, parses dynamic JSON payloads, and persists historical time-series entries into SQL.

Python SQL Scheduling / Cron REST APIs Time-Series

Project Overview

While many public APIs provide real-time updates on weather measurements, foreign currency exchange rates, or cryptocurrency indices, free endpoints rarely retain multi-month historical archives. This project demonstrates how to build an automated ingestion daemon that snapshots live values daily, stores them persistently in a database, and tracks delta variations over time.

Key Architectural Features

1. Resilient HTTP Request Engine

Uses Python requests with connection pooling, exponential backoff retries, and explicit response status code validation to withstand transient internet drops.

2. Schema & Payload Normalization

Flattens deeply nested JSON responses into clean key-value records, attaching UTC timestamps and calculating 24-hour delta changes prior to database writing.

3. Scheduled Execution

Configured via Cron job schedule (0 0 * * *) and Python's schedule module to run seamlessly in the background with local log file tracking.

Worker Script Implementation

import time
import requests
import sqlite3
from datetime import datetime
import schedule

DB_PATH = "data/market_history.db"

def init_db():
    with sqlite3.connect(DB_PATH) as conn:
        conn.execute("""
            CREATE TABLE IF NOT EXISTS currency_rates (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                recorded_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
                base_currency TEXT,
                target_currency TEXT,
                rate REAL,
                delta_prev REAL
            );
        """)

def fetch_and_store_rates():
    url = "https://open.er-api.com/v6/latest/USD"
    print(f"[{datetime.now()}] Pulling rate updates from API...")
    
    try:
        response = requests.get(url, timeout=12)
        response.raise_for_status()
        data = response.json()
        
        rates = data.get("rates", {})
        tracked = ["EUR", "GBP", "EGP", "JPY", "CAD"]

        with sqlite3.connect(DB_PATH) as conn:
            cursor = conn.cursor()
            for curr in tracked:
                val = rates.get(curr)
                # Fetch last known rate to compute percentage delta
                cursor.execute(
                    "SELECT rate FROM currency_rates WHERE target_currency = ? ORDER BY id DESC LIMIT 1",
                    (curr,)
                )
                last_row = cursor.fetchone()
                last_val = last_row[0] if last_row else val
                delta = ((val - last_val) / last_val) * 100 if last_val else 0.0

                cursor.execute("""
                    INSERT INTO currency_rates (base_currency, target_currency, rate, delta_prev)
                    VALUES ('USD', ?, ?, ?)
                """, (curr, val, round(delta, 4)))
            conn.commit()
            print(f"[{datetime.now()}] Successfully saved {len(tracked)} currency entries.")

    except Exception as err:
        print(f"Error executing poller: {err}")

# Schedule task every day at 00:00 midnight
schedule.every().day.at("00:00").do(fetch_and_store_rates)

if __name__ == "__main__":
    init_db()
    fetch_and_store_rates() # Immediate test run
    while True:
        schedule.run_pending()
        time.sleep(60)
