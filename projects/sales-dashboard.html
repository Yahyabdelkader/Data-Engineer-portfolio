Practice Project

Sales Performance Dashboard

An interactive business intelligence dashboard built on top of the relational sales database, visualizing revenue velocity, product rankings, and monthly growth trends.

SQL Power BI Tableau Analytical Views Data Modeling

Project Overview

Raw database tables contain rich operational details, but business leaders need instant answers: Which product categories are driving maximum margin? How does this month's revenue compare to historical periods? What is the order velocity per sales region? This project bridges the gap between database engineering and executive decision making.

Core Metrics & Visual Structure

Executive KPI Cards

High-contrast summary indicators delivering immediate high-level feedback: Gross Revenue ($248,500), Total Processed Orders (3,420), and Average Order Value ($72.66).

Monthly Trend & Seasonality Analysis

Time-series bar and line visual calculating Month-over-Month (MoM) percentage shifts and identifying seasonal transaction spikes across quarters.

Product Ranking & Contribution

Ranked horizontal distribution isolating the top revenue drivers (Enterprise Suite, Cloud Storage Add-on) and identifying underperforming SKU segments.

SQL Analytical Modeling

-- Aggregated monthly KPI view for BI direct ingestion
CREATE OR REPLACE VIEW analytics.monthly_revenue_kpis AS
WITH monthly_data AS (
    SELECT 
        DATE_TRUNC('month', order_date) AS order_month,
        product_category,
        COUNT(DISTINCT order_id) AS total_orders,
        SUM(net_amount) AS monthly_revenue
    FROM staging.fact_sales
    WHERE order_status = 'Delivered'
    GROUP BY 1, 2
)
SELECT 
    order_month,
    product_category,
    total_orders,
    monthly_revenue,
    -- Calculate previous month revenue via SQL Window Function
    LAG(monthly_revenue, 1) OVER (
        PARTITION BY product_category ORDER BY order_month
    ) AS prior_month_revenue,
    ROUND(
        (monthly_revenue - LAG(monthly_revenue, 1) OVER (
            PARTITION BY product_category ORDER BY order_month
        )) / NULLIF(LAG(monthly_revenue, 1) OVER (
            PARTITION BY product_category ORDER BY order_month
        ), 0) * 100, 2
    ) AS mom_growth_pct
FROM monthly_data;

Key Takeaways & Engineering Skills

  • Writing maintainable SQL Common Table Expressions (CTEs) and Window Functions.
  • Connecting BI tools directly to relational database schemas without performance bottlenecks.
  • Applying design hierarchy principles to prevent dashboard clutter.
  • Formulating actionable business indicators rather than simply displaying raw metrics.
