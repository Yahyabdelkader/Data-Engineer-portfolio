Sales Data ETL Pipeline

A Python and SQL automated data pipeline that extracts a messy CSV sales dataset, cleans and normalizes it with Pandas, and loads it into a relational SQL database.

Python Pandas SQL PostgreSQL SQLAlchemy

Project Overview

In commercial data environments, raw source files are frequently compromised with inconsistent formatting, misplaced delimiters, duplicate order entries, and invalid null timestamps. This practice project simulates an end-to-end data ingestion workflow that handles real-world transactional anomalies and transforms messy records into clean, query-ready relational tables.

Pipeline Workflow

1. Extraction

Reads raw CSV files with varied date formats and currency strings. Performs chunk-based reading to optimize memory utilization when handling thousands of rows.

2. Cleansing & Transformation

Strips symbols and currency marks, casts numeric fields to strict decimals, harmonizes datetime entries into standard ISO-8601 formatting, and drops corrupted records lacking mandatory IDs.

3. Loading to SQL Warehouse

Defines a dimensional schema with fact and dimension tables. Utilizes SQLAlchemy and PostgreSQL upserts (ON CONFLICT DO UPDATE) to prevent duplicate key errors during recurrent loads.

Pipeline Code Implementation

import pandas as pd
from sqlalchemy import create_engine

def run_etl_pipeline(csv_path: str, db_connection_url: str):
    print(">> Extracting raw sales dataset...")
    df_raw = pd.read_csv(csv_path)

    print(f">> Transforming {len(df_raw)} records...")
    # Deduplicate transaction identifiers
    df = df_raw.drop_duplicates(subset=['transaction_id']).copy()

    # Clean currency and float conversion
    df['sales_amount'] = (
        df['sales_amount']
        .astype(str)
        .str.replace(r'[\$,]', '', regex=True)
        .astype(float)
    )

    # Standardize inconsistent dates
    df['order_date'] = pd.to_datetime(df['order_date'], errors='coerce')
    
    # Filter unrecoverable nulls
    clean_df = df.dropna(subset=['transaction_id', 'order_date', 'customer_id'])

    print(f">> Loading {len(clean_df)} sanitized records to SQL...")
    engine = create_engine(db_connection_url)
    clean_df.to_sql('fact_sales_orders', con=engine, if_exists='append', index=False)
    print(">> ETL Pipeline completed successfully!")

if __name__ == "__main__":
    run_etl_pipeline("data/messy_sales.csv", "postgresql://user:pass@localhost:5432/warehouse")

Key Takeaways & Engineering Skills

  • Implementing vectorized operations in Pandas rather than costly row iteration.
  • Designing normalized relational SQL schemas with foreign key integrity.
  • Enforcing atomic database transactions to ensure rollbacks on unexpected failures.
